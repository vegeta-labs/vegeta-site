# Due-diligence note

> Bulma v0.1.0. Source: https://github.com/vegeta-labs/bulma/blob/e0166a67c51edebce77f91d0d53c208b292cdebb/docs/en/due-diligence.md

For anyone deciding whether to rely on this software.

- **No vendor.** It is an open-source project. There is no company selling or standing behind it.
- **No SLA** and no support commitment.
- **No warranty**, beyond what the Apache-2.0 licence states, which is none.
- **No penetration test has been done.** This line changes if one is.
- **To report a vulnerability**, follow [SECURITY.md](https://github.com/vegeta-labs/bulma/blob/e0166a67c51edebce77f91d0d53c208b292cdebb/SECURITY.md).
- **The regulatory status of the project is unresolved.** Whether publishing or supporting this software is itself a regulated activity has no settled answer. No lawyer has reviewed the project.
- **One operator only.** The first version suits one operator running its own deals. It cannot supervise appointed representatives.
- **Sandbox limits and declarations are friction, not control.** Anyone can state anything to reach the real mode, and anyone can change the code.
- **The project runs no real deals.** It reviews no one's deals and takes no fee or carry.

See [who does what](https://vegeta-ops.vercel.app/docs/bulma/build/responsibilities.md).
